## Intent of each conflict, and the fix

- **Security hardening, in six inputs** (pr/7, pr/8, pr/9, pr/13, middle/pr-5 and the omnibus pr/25: CRIT-01..04, HIGH-01..05, MED-01..06, LOW-01..04). The trunk
  already holds the checks (fread results, size_t arithmetic, dispatch_once init, calloc checks, token range); its side stays. What it lacked came in:
  HIGH-03 (release the mapping before `exec()`, resolve argv[0]), HIGH-05 (`step_ok` across accumulation steps), the audit report and diary (pr/13's complete
  versions: 19 findings, all marked fixed).
- **Token data** (pr/30, pr/38, #48 in the trunk): pr/30's `data_validation.h` checks byte count, emptiness, minimum length and vocabulary range and has a
  C test (`test_data_validation`, 18/18); it replaces the short-dataset guards in `train_large`, `train_large_ane` and `training_dynamic`, keeping the trunk's
  configurable data path. The descriptor closes right after `mmap`, so the `close()` before `exec()` was removed.
- **ANE SDK** (pr/18): multi-input kernels. `compile_kern_mil_multi` has the new signature; `compile_kern_mil_w` keeps its own for its 48 call sites; `Kern`
  keeps `ioIn` as `inputs[0]`. The SDK (`layers/`), its tests and `benchmark_ane` came in, with the weights-as-tensors generators beside the baked ones in
  `stories_mil.h`. pr/18's rewrite of `train_large.m` (weights as input tensors) was not taken: `training_dynamic/` is the same idea, in the trunk.
- **MIL syntax variants** (pr/6 and the same in pr/25: `program(1.0)`, `ios16`, `tensor<string, []>` scalars, for M1/M2): not taken in the generators; the
  trunk's syntax runs on this M3 Pro, the variant was not trialled. pr/25's `g_fp16_io` branches and GQA functions, which its inference engine needs, were
  transplanted. pr/35's runtime chip detection (`ane_get_mil_version()`) came in.
- **Makefile**: one file with every target the inputs added (SDK, research probes, M5 suites, data validation, `setup`/`data`, `verify-flags`,
  `check-deprecated`); 13 targets before, 34 after (21 added, none removed).
- **`inference/`** (pr/26, then pr/25's Metal, Q4 and HTTP extension): pr/25's files. **READMEs**: the root README keeps the trunk's text where inputs
  conflicted and takes the clean hunks of pr/16 (its GPT-2 section), pr/35, pr/41 and pr/53 and the Community Benchmarks section of pr/28; `training/README.md` is
  pr/18's, with its SDK section. **`.gitignore`**: one list (every branch had added its own to a trunk that had none).
